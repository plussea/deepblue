# v0.6：Web 可靠性与会话体验

本阶段随 **v0.7.0** 合并交付，未单独发布 v0.6 包。关联 [#9](https://github.com/plussea/deepblue/issues/9)、[#10](https://github.com/plussea/deepblue/issues/10)、[#11](https://github.com/plussea/deepblue/issues/11)，总路线见 [#8](https://github.com/plussea/deepblue/issues/8)。

## 任务可靠性

- 创建任务返回 `job_id` / `session_id`；浏览器生成 `request_id`，服务端保存请求摘要。重复发送相同请求返回原任务；相同 ID 配不同内容会被拒绝。
- 最小任务元数据以原子文件写入并 fsync，保存于当前项目会话目录的 `web-jobs/`。凭据和任务正文不进入这些元数据；原始会话依然保存在 JSONL。
- Web 使用带 Token 请求头的 fetch SSE，20 秒分段连接、5 秒心跳、事件序号及有界快照；不把 Token 放入 URL。连接失败退避，连续失败达到上限后停止，用户可显式重新连接。SSE 不可用时退回轮询。
- 事件缓存最多 2000 条；游标过期返回最近任务快照。快照最多 200 个展示项，单段累计文本最多 128000 字符；完整历史通过会话分页访问。
- 停止必须指定任务 ID。旧标签页不能借“停止当前任务”误停新任务；停止不会回滚文件。
- 服务重启将未结束任务标记 interrupted/unknown，写入原取消标记通知可能仍存活的 worker；不按旧 PID 操作、不自动重放。旧 worker 的会话锁未释放时拒绝启动新任务。
- 修复异步提交的默认表单行为、快速双击、过期会话响应、强制滚动和无限重试。用户向上阅读时显示新消息提示。

## 会话体验

- 会话列表默认每页 50 条，可加载更多；历史默认每页 100 条，向前加载保留当前位置。
- 标题/内容搜索、重命名、归档/恢复、Markdown/JSON 导出。归档不删除原始记录，运行中会话不能归档。
- 只读索引按 JSONL 完整行增量更新，不获取 worker 的写锁，不修复半行尾部。缓存最多 128 个会话，重启可从日志重建；外部替换、缩短或同长度改写会失效。
- 冷读取仍需扫描对应会话，全文搜索仍需遍历项目会话；暖读取只解析新增日志。索引不是数据库，也未承诺超大型历史的恒定内存开销。
- 草稿与验收命令按项目/会话保存在当前浏览器 localStorage，支持刷新恢复和清除。任务运行时允许浏览其他会话，全局仍只执行一个任务。
- 提交响应丢失时先按 request_id 查询任务。不会在后台自动重发用户任务；明确的客户端错误保留输入并释放待确认状态。

## DeepSeek 设置

- 左下角设置面板管理模型、API 地址、网络超时与 Key；继续只支持 DeepSeek 协议。既有会话沿用会话头中的模型，新模型设置用于新会话。
- 环境变量管理的项目在网页中锁定。未由环境提供的 Key 可输入或清除，只保留在本次服务进程内，不写磁盘、不存 localStorage、不回显；服务重启后重新输入。
- 设置提交先验证再整体生效；新任务冻结模型连接设置和 Key。工具 Shell 子进程仍移除两种 Key 环境变量。
- 连接测试必须点击“测试连接（调用 API）”，发起一次小请求；不会定时测试或自动付费重试。错误区分认证、余额、限流和网络问题。
- 对本进程见过的 Key 做输出字符串精确脱敏。它不是通用秘密扫描器，不应把任何凭据放进任务正文。

## 验证与边界

测试覆盖提交幂等与重启查询、缓存缺口快照、指定 ID 取消、真实服务进程强制退出、旧 worker 释放写锁、长历史分页、105 个会话、增量读取、归档搜索导出、配置冻结/脱敏/非法值与 SSE 鉴权。浏览器用本机模拟模型覆盖草稿、双击、断线刷新、取消、双标签页和窄屏。

版本总验收记录见 [v0.7](v0.7.md)。源码同步状态见仓库提交历史和对应 Issue，不等同于包发布。
