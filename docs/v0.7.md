# v0.7：编码审阅与证据查看

当前包版本 **0.7.0**，包含 v0.6 的任务、会话和配置能力。关联 [#12](https://github.com/plussea/deepblue/issues/12)、[#13](https://github.com/plussea/deepblue/issues/13)。

## 消息与文件

- 安全 DOM 渲染常用 Markdown：标题、段落、列表、引用、表格、链接、行内代码与围栏代码块；代码复制和轻量词法高亮。
- 不执行原始 HTML，不允许 javascript/data 等链接协议。外部链接仅 HTTP(S)，项目文件链接交由有边界的文件接口处理；不是完整 CommonMark、Mermaid 或数学公式渲染器。
- 工具卡片显示状态、结果、退出码和新操作耗时。长消息先展示 16000 字符，可按 32000 字符分段读取原文。
- “状态”中的工具日志通过注册 operation_id 访问，运行中每秒增量读取，关闭对话框停止读取。工具取消不代表日志已记录全部副作用。
- 项目文件名/路径搜索、内容查找、行号与行定位、预览刷新；文件树及搜索跳过符号链接/目录联接和常见生成目录。
- 输入 `@` 选择文件或点击“引用文件”，生成 `@"相对路径"`；提交时服务端验证存在及工作区边界，追加明确路径提示，由 Agent 的 read 工具读取，不自动注入整个文件内容。
- 文本预览最多 256000 字节；文件搜索最多返回 100 项、扫描 20000 个文件，有上限提示。暂不提供文件上传/编辑器/多媒体预览。

## 修改审阅与验收

- “修改”页提供只读 Git 状态，分别查看暂存、未暂存和未跟踪文本；支持 Git 仓库内子目录。Git 参数通过 argv 传递，关闭外部 diff/textconv，不调用提交或重置。
- 任务开始记录已有修改及可取得的文件内容哈希。界面标明任务前已改文件，并提供完整基线文件清单；工作区差异不能全部归因于 Agent，也不提供并发修改的事务归属证明。
- 非 Git 工作区显示会话已记录的 write/edit 操作及 diff；这只覆盖 Agent 观察到的操作，不是整目录快照。
- 验收详情展示命令、cwd、退出码、耗时、指纹和原始状态，顶部状态重新核对当前文件；变更后显示“证据已过期”。“指定检查通过”不等同于任务绝对正确。
- 日志通过注册 verification_id/operation_id 访问，并验证目标仍位于该会话工件目录；不接受任意日志路径。日志每段最多 32000 字节，UTF-8 分页避免正常字符被拆断。
- 恢复报告显示未确认操作、观察文件变化和后续建议；不自动重跑、回滚或根据旧 PID 接管进程。

## 架构与运行

Python 标准库后端拆为 `web.py`（HTTP）、`web_jobs.py`（任务）、`web_sessions.py`（增量索引）、`web_workspace.py`（会话/配置/证据）、`web_review.py`（Git）。继续共用 CLI 的 Agent/Session/验收/恢复实现。

前端使用原生 ES modules，拆分 API、连接、会话、消息渲染和文件模块。无需 Node 构建或 CDN，无第三方运行时依赖。Node/Playwright 仅用于开发验收。

```powershell
# Python 回归
$env:PYTHONPATH = "src"
python -W error::ResourceWarning -m unittest discover -s tests -v

# 浏览器回归（需安装开发依赖及浏览器）
npm install
npx playwright install chromium
$env:DEEPBLUE_PYTHON = "python"
npm run test:web
```

也可用 `PLAYWRIGHT_MODULE` 指定已安装的 Playwright 模块路径，`CHROME_PATH` 指定 Chrome 可执行文件。`scripts/web_e2e_server.py` 自动创建隔离项目、会话、Git 夹具和本机模拟 API；不使用真实 Key，不调用真实 DeepSeek。浏览器报告、截图与导出样本在 `.test-tmp/web-e2e-*/`。
