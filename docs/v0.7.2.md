## 本次发现与修复

受控 401 场景发现：任务结束后重新加载会话会清空临时事件，导致具体模型错误消失，只显示“执行异常”。

现在任务元数据保存最多 6 条、每条最多 2000 字符的脱敏诊断，任务结束、页面刷新和服务重启后仍可读取。常规完成提示与摘要进度不重复保存。新任务只展示自身诊断；状态优先采用最新 Web 任务结果，避免压缩结果被上一轮状态覆盖。

短会话压缩后如果更大，会保留原文、不增加压缩次数。这是已有保护行为；现在“无需压缩”的结果也不会在刷新会话时消失。

2. **编码与验收**：先独立确认临时计算器测试失败；模型通过 `read` / `edit` 修复 `add`，测试文件哈希不变；刷新浏览器接回同一任务，指定检查与独立 Python 检查均通过，页面可打开包含 `OK` 的证据日志。

### 受控故障与真实接口的边界

401、429、超时和 SSE 缺少 `[DONE]` 由本机 HTTP 服务注入，不尝试耗尽真实账户余额或触发真实限流。测试验证错误原因在刷新后保留、上游回显的假 Key 不泄漏；断流中的完整工具参数也不会执行。工具读取不存在文件另验为工具卡片“未完成”，不混成模型连接错误。

真实 API 部分用于验证实际启动、鉴权、模型协议、工具闭环及界面恢复，不证明任意任务成功率。跨平台验收、长任务质量对照、真实仓库保留集评测，以及 v0.8 多项目/分叉/队列仍未完成。

## 复现

常规测试：

```powershell
$env:PYTHONPATH = "src"
python -W error::ResourceWarning -m unittest discover -s tests -v
npm install
npm run test:web
```

Playwright 可用 `CHROME_PATH` 指向现有 Chrome；`PLAYWRIGHT_MODULE` 可指向已安装的 Playwright 模块，`DEEPBLUE_PYTHON` 指定 Python 3.10 以上解释器。

真实收费验收：先以当前仓库为工作目录启动 Web 并配置 Key，确认没有其他运行任务，然后执行 `npm run test:web:live`。详见 [README](../README.md#真实-web-验收显式收费)。验收期间不要修改工作区，否则文件指纹可能把检查证据标为过期。
