# DeepBlue v0.3：程序化验收与最小评测骨架

对应 [Issue #4](https://github.com/plussea/deepblue/issues/4)。本轮落实后续路线阶段 A/B 的最小实现。阶段 C/D 的自动上下文管理和工作区恢复尚未实施。

## 实现

- `verification.py`：显式命令配置、验证执行、前后文件指纹、证据文件和过期判断。
- `agent.py`：模型结束后检查，普通非零退出可回传模型有限修复；修复与原任务共享 `max_steps`。超时、运行错误、取消和证据过期不会自动重复执行。
- `models.py`：兼容原 `status`，新增 `execution_status`、`verification_status`、任务/运行 ID 和证据；CLI 根据验收状态决定一次性运行退出码。
- `session.py`：追加运行开始和结束记录，保存验证、用量与耗时。恢复读取最新记录；不自动恢复执行历史验收命令。中断未完成的运行保留 `running`，不能解读为成功。
- `cli.py`：`--verify`、`--verify-cwd`、`--verify-timeout`、`--verify-repairs`、`--verify-not-applicable`；`/status` 核对最近通过记录是否过期。
- `evaluation.py` 与 `scripts/evaluate.py`：5 个小型开发任务，每轮独立工作副本，公开示例检查与评测器独立断言分离，统一输出 JSON 报告。

## 状态与证据语义

`finished` 只表示模型结束。没有检查是 `unverified`，显式纯解释声明是 `not_applicable`；命令退出 0 且检查前后内容指纹一致才记录 `passed`。仅针对该命令覆盖的范围，不代表完整需求证明。

指纹包含未提交文件与未跟踪文件；记录排除目录、根路径和文件哈希。它不包含依赖安装状态，也不是并发文件系统事务或内容隔离。检查前后之间文件临时改变又恢复、扫描结束后外部编辑等情况，不能由该机制完全检测。`/status` 的重新扫描只代表查询时刻。

普通非零退出记为 `failed`，保留原始退出码与日志；任意 Shell 命令无法通用地区分断言失败与环境缺失，当前不根据错误文本猜测。执行器启动失败、超时、输出超限或指纹失败记为 `error`。检查本身更改工作区时记为 `stale`，保守地不认定当前版本通过。

指纹扫描限制：20,000 个目录项、128 MiB、约 10 秒；拒绝链接/联接点和非常规文件。排除 `.git`、`__pycache__`、`.venv`、`node_modules`、`.pytest_cache` 和会话根目录；详细清单写入证据。验证命令仍按当前用户权限执行。

## 开发评测与边界

夹具为加法修复、保序去重、区间限制、平均值和跨文件订单求和。不是从真实仓库抽取的任务，也不是最终保留测试集。

脚本提供 `baseline` 和 `verified` 两组，使用相同任务和可配置的模型轮数、输出 Token 上限；模型解码参数沿用服务默认值，关闭 thinking。记录模型名、源码指纹、Git HEAD、Python/系统版本、运行 ID、初始工作区指纹、证据和用量。Git HEAD 不能代表未提交源码，因此另记实际源码指纹。

真实运行需要显式 `--live`，可指定任务、重复次数和预算。当前没有执行批量收费评测，也没有真实任务完成率或收益数据。5 个夹具和参考实现仅验证评测器可以识别失败与成功。

独立断言在评测器中，不写入 Agent 的工作副本。但相同用户权限的任意 Shell 可以访问其他文件，因此该方案不提供对抗性验收隔离。不能声称已满足路线中完整的外部验收保护要求。

`false_finished_rate` 使用模型结束作为操作性代理，不分析模型是否在自然语言中明确声称完成。记录所有已尝试运行及错误，不删除失败样本；成功率为独立通过数/尝试数。费用未计算；Token 为已返回用量的合计，缺失用量单独记录。未成功时每成功成本为 null。

## 本地验证

Windows / Python 3.12：73 项回归测试通过（启用 ResourceWarning 错误检查）。其中新增覆盖：

- 声称完成但检查失败，CLI 非零退出。
- 检查失败 → 模型修复 → 再检查通过，恢复后证据仍可读取。
- 修复次数和共享模型调用上限。
- 验收超时、启动失败、取消及证据保存。
- 未配置检查、显式不适用和新任务重置。
- 修改源码后旧通过记录过期；检查自身修改工作区时不显示通过。
- 未跟踪文件进入指纹，缓存目录排除，扫描失败不执行检查。
- 5 个夹具初始均失败、参考实现均通过。
- 本机 HTTP 模型服务驱动完整评测脚本，确认失败样本进入报告；不调用真实 API。

wheel 构建、独立目录安装以及安装后 CLI 的 `--version` / `--help` 检查通过，版本为 0.3.0。最后的指纹扫描保护与用量缺失统计调整后，另行复测 13 项验收/评测测试通过。Linux/macOS 尚未验收。
